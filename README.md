# معلّم برو

مكتبة برومبتات عملية مرتبة حسب حاجة المعلم — واجهة عربية (RTL) متجاوبة للجوال أولًا.

## ماذا يقدّم؟

- 26 برومبتًا جاهزًا للتحضير، الاختبارات، التحليل، الرصد، أولياء الأمور، التوثيق، الأنشطة، والدعم.
- بحث وتصفية حسب الفئة.
- نسخ سريع مع تنبيه «تم النسخ».
- محوّل يطلب منك نصًا ويحوّله إلى برومبت منظّم دون اختراع أسماء أو درجات أو تعاميم.

## تنبيه مهم

معلّم برو أداة مساعدة **مستقلة وغير رسمية**، وغير تابعة لوزارة التعليم ولا لأي جهة حكومية. لا تستخدم شعارات رسمية.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

المخرجات في مجلد `dist/` مع المسار الأساسي `/muallim-pro/` لنشر GitHub Pages.

## النشر

يوجد سير عمل GitHub Actions في `.github/workflows/deploy-pages.yml` للبناء والنشر على GitHub Pages عند الدفع إلى `main`.
